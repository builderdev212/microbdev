# Kratos
Kratos is a 32-bit RISC-V CPU which supports the RV32I ISA (v2.2).  

## Vision
The goal of this core is to create a small but functional CPU that  
can be fully implemented on smaller FPGAs. The long term goal is  
to design other peripherals around this CPU and to support other  
extensions of the RISC-V architecture.
